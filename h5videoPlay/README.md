# HTML5视频播放工具

## 功能特性

- ✅ 支持 `<video>` 和 `<audio>` 元素倍速控制
- ✅ 可视化倍速UI (拖动滑块 + 预设按钮)
- ✅ 视频截图、画中画、缓存
- ✅ 全屏、网页全屏
- ✅ 字幕服务
- ✅ 万能网页全屏

## 快捷键

### 倍速控制
| 按键 | 功能 |
|------|------|
| **Q** | 显示/隐藏倍速面板 |
| **E** | 加速 +0.1x |
| **C** (YouTube用V) | 加速 +0.1x |
| **X** (抖音用S) | 减速 -0.1x |
| **Z** (抖音用A) | 1.0x ↔ 记忆速度 |

### 其他功能
| 按键 | 功能 |
|------|------|
| **P** | 视频截图 |
| **I** | 画中画 |
| **M** | 缓存视频 |
| **S** | 字幕服务 |
| **N** | 下一集 |
| **F / Enter** | 全屏 |
| **Shift+Enter** | 网页全屏 |
| **←→** | 快进/快退 5秒 |
| **Shift+←→** | 快进/快退 20秒 |
| **↑↓** | 音量调节 |
| **D** | 上一帧 |
| **G** (YouTube用E) | 下一帧 |
| **Space** | 暂停/播放 |
| **ESC** | 退出全屏 |

## 倍速UI使用

### 显示面板
```
按 Q 键
```

### 调节速度
- **预设按钮**: 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x
- **拖动滑块**: 0.25x - 4.0x 精确调节
- **键盘微调**: E键 +0.1x, X键 -0.1x

### 特性
- 3秒自动隐藏
- 鼠标悬停保持显示
- 实时速度同步

## 更新记录

### v2.1.8 (2026-08-29)
- 🐛 修复: 部分自研播放器上按加/减速键（C/X）后速度提示一闪即被打回、无法真正倍速。定位到根因：这类播放器只接受离散档位（如 0.5/1/1.5/2，上限 2.0），会在自身 `ratechange` 处理里把脚本 +0.1 步进产生的"非法"速率（1.1、1.6、2.1 等）钳制回最近的合法档位。修复：在捕获阶段监听 `ratechange`，当实际速率已等于脚本期望值时 `stopImmediatePropagation`，阻止站点钳制回调执行，从而支持任意倍速。油猴与扩展版同步适配。

### v2.1.7 (2026-08-28)
- 🐛 修复: 部分网站上加速快捷键不响应。根因是站点在捕获阶段拦截了键盘事件，仅捕获阶段监听会被绕过；新增冒泡阶段监听作为兜底，双重保险。
- 🐛 修复: YouTube 等站点加速后，视频实际按新速率播放但倍速菜单仍显示"正常"/未同步。根因是这类播放器的菜单文案取自内部状态而非 video.playbackRate；新增站点 UI 同步器：
  - YouTube: 调用 `movie_player.setPlaybackRate` 更新内部状态（受官方档位限制，超过 2 倍时菜单显示 2，但实际速率仍由 guard 锁定为期望值）
  - 通用兜底: 探测 `window.__PLAYER__ / PLAYER / player`、`video._player / player / __player` 等常见播放器实例，尝试其 setPlaybackRate/playbackRate API，覆盖腾讯、B 站、xgplayer/dplayer/artplayer 等常见 H5 播放器
  - 事件兜底: 额外派发一次 `ratechange` 事件，应对通过事件驱动 UI 更新且 stopPropagation 了原生派发的场景
- 📦 油猴脚本与 Chrome 扩展版本同步升级至 2.1.7。

### v2.1.6 (2026-07-18)
- 🐛 修复: 部分网站（如自研播放器）加减速快捷键只能生效一次、按多次不变的问题。根因是这类播放器会在外部修改 playbackRate 后强制拉回内部记录值；新增 setPlaybackRate 守卫，在 video 实例上锁定期望速率，抵御站点拉回。油猴与扩展版同步适配。

### v2.1.5 (2026-07-11)
- ✨ 新增: 反失焦暂停——去除部分网站在鼠标移出窗口/切换标签时自动暂停视频的限制（伪装页面始终可见 + 拦截 visibilitychange/blur/pagehide 等失焦事件监听）
- ⚙️ 油猴脚本可通过菜单「本站关闭"反失焦暂停"」针对个别网站关闭；扩展可用 `localStorage.h5video_antiPause_off = '1'` 关闭

### v2.1.4 (2026-07-11)

## 常见问题

**Q: 倍速面板不显示?**  
A: 确认页面有视频/音频,按Q键手动显示,或刷新页面

**Q: 音频不支持倍速?**  
A: 确认是HTML5 audio元素,某些Flash播放器不支持

**Q: 快捷键冲突?**  
A: YouTube/抖音已自动重映射快捷键避免冲突
