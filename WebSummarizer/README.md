# 网页智能总结 - 油猴脚本

一个通用的网页 AI 总结工具，支持多种 AI 引擎，可在任意网页一键提取正文并生成结构化总结，同时给出「AI 生成概率」评分。

## 功能

- **多 AI 引擎**：OpenAI / Anthropic Claude / Ollama（本地免费）/ Chrome Gemini（浏览器内置，零配置）/ Dify 工作流，统一配置界面一键切换。
- **两种总结模式**：
  - 全文总结：一键总结整个页面正文。
  - 选中文本总结：选中任意文本（≥50 字符）后点击按钮，只总结选中部分。按钮会自动切换图标与文字提示。
- **智能内容提取**：三层策略自动定位正文，过滤导航、侧边栏、广告、评论等无关内容。
- **AI 生成概率评分**：总结结果顶部显示内容由 AI 生成的概率（0-100）。
- **浮动按钮**：可拖动、松手自动贴边；支持自由定位与贴边两种模式，位置本地记忆。
- **结果面板**：支持拖动、全屏、最小化（不中断总结，方便查看原文）、一键复制，Markdown 渲染。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Firefox / Edge 均可）。
2. 点击安装脚本（已配置 `@updateURL`，后续自动更新）：
   [web_summarizer.js](https://raw.githubusercontent.com/xixiU/awesome-script/refs/heads/master/WebSummarizer/web_summarizer.js)
   或在 Tampermonkey 中新建脚本，粘贴 `web_summarizer.js` 全部内容后保存。

## 配置

首次使用需选择并配置一个 AI 提供商：

1. 打开任意网页，点击油猴菜单 → 打开设置，或点击页面上的 ⚙️ 按钮。
2. 选择 AI 提供商，配置界面会**自动显示/隐藏**对应字段：
   - **Chrome Gemini**：无需 API Key 和地址，仅需模型名（推荐新手，零成本、本地运行）。
   - **OpenAI / Anthropic**：填写 API 地址 + API Key + 模型。
   - **Ollama**：填写 API 地址 + 模型（本地部署，无需 Key）。
   - **Dify**：填写 Dify 工作流的 API 地址与 Key。
3. 保存后即可使用。配置存储在浏览器本地，升级脚本不丢失。

### 各引擎前置条件

| 引擎 | 前置要求 |
| --- | --- |
| Chrome Gemini | Chrome 127+，在 `chrome://flags/#prompt-api-for-gemini-nano` 启用，`chrome://components/` 下载 Gemini Nano 模型 |
| OpenAI | [API Key](https://platform.openai.com/api-keys) |
| Anthropic | [API Key](https://console.anthropic.com/) |
| Ollama | 安装 [Ollama](https://ollama.ai/) 并运行模型，如 `ollama run llama3` |
| Dify | Dify 工作流，输入参数含 `newsUrl`、`newsContent` |

## 使用方法

- **全文总结**：打开网页，点击右下角 📝 AI总结 按钮，等待结果面板弹出。
- **选中文本总结**：拖选文本后按钮变为 ✂️ 总结选中，点击即可只总结选中内容。
- **面板操作**：拖动标题栏移动位置；⤢ 全屏；− 最小化（后台继续总结，点击遮罩或按钮恢复）；📋 复制。
- **按钮操作**：长按拖动可调整位置，松手自动贴边。

## 内容提取原理

脚本采用三层策略提取正文：

1. **常见选择器匹配**：`article`、`main`、`.article-content`、`.post-content`、`.markdown-body` 等。
2. **文本密度算法**：常见选择器失效时，综合文本长度、链接密度、标点密度、段落数量评分选出最佳正文区域。
3. **Body 回退**：以上均失败时从 `body` 提取并清理。

如需针对特定网站优化，可在 `ContentExtractor` 类的 `contentSelectors` 数组中新增选择器。

### 站点适配器（结构化增强）

对内容结构特殊的站点（如知乎问答的「多回答 + 评论」），脚本提供站点适配器机制，优先于通用提取器：

- 命中 URL 的适配器会做**结构化抓取**（区分回答、评论、赞同数等），并使用专属提示词。
- 目前内置**知乎问答适配器**：抓取全部回答及其评论/子评论，输出多方观点的定性+定量分析。
- 适配器抓取失败时自动回退通用提取器，保证不影响其他站点。
- 新增站点：实现 `SiteAdapter` 的 `match / extract / formatForLLM / promptType`，再 `siteAdapterRegistry.register(...)` 即可。

## 故障排除

- **点击无反应**：F12 查看控制台错误，确认 AI 提供商已正确配置。
- **提取内容不准**：控制台会输出提取日志，可为该网站补充专属选择器。
- **API 调用失败**：检查 API 地址、Key 是否有效及额度，查看控制台错误详情。

- 扩展方式：实现 `SiteAdapter` 的 `match/extract/formatForLLM/promptType` 四个方法并注册，即可支持新站点（如文学城、Reddit）。
