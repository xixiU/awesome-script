## 一、功能概述

该考试系统实现了防作弊的切屏检测功能，当考生在考试过程中切换到其他窗口、最小化浏览器或切换标签页时，系统会记录切屏次数，累计达到3次将强制交卷。

### 防舞弊规则
- **切屏限制**：累计切屏3次强制交卷
- **检测范围**：
  - 浏览器窗口失焦（切换到其他应用）
  - 浏览器标签页切换
  - 浏览器最小化
  - 手机来电/接听/休眠（移动端）

## 四、技术要点

### 4.1 检测时机
- **仅在考试答题页面激活**：考试列表页面不启用监控
- **页面加载完成后初始化**：确保监听器正确绑定

### 4.2 事件去重
为避免误报，可能采用以下策略：
- **短时间内多次事件合并**：防止快速切换导致的重复上报
- **时间阈值**：小于某个时长的切屏可能被忽略

### 4.3 服务端验证
- 切屏次数存储在服务端
- 前端无法篡改切屏计数
- 达到阈值后服务端强制结束考试

## 五、可能的实现代码示例

### 5.1 前端监听器初始化
```javascript
// 切屏检测管理器
class ScreenMonitor {
  constructor() {
    this.switchCount = 0;
    this.maxSwitchCount = 3;
    this.isMonitoring = false;
    this.lastSwitchTime = 0;
    this.debounceDelay = 1000; // 1秒内的重复事件忽略
  }
  
  // 启动监控
  start() {
    if (this.isMonitoring) return;
    
    this.isMonitoring = true;
    
    // 监听 visibilitychange
    document.addEventListener('visibilitychange', this.handleVisibilityChange.bind(this));
    
    // 监听 blur
    window.addEventListener('blur', this.handleBlur.bind(this));
  }
  
  // 停止监控
  stop() {
    this.isMonitoring = false;
    document.removeEventListener('visibilitychange', this.handleVisibilityChange);
    window.removeEventListener('blur', this.handleBlur);
  }
  
  // 处理可见性变化
  handleVisibilityChange() {
    if (document.hidden && this.isMonitoring) {
      this.recordSwitch('visibilitychange');
    }
  }
  
  // 处理窗口失焦
  handleBlur() {
    if (this.isMonitoring) {
      this.recordSwitch('blur');
    }
  }
  
  // 记录切屏
  recordSwitch(type) {
    const now = Date.now();
    
    // 防抖：1秒内的重复事件忽略
    if (now - this.lastSwitchTime < this.debounceDelay) {
      return;
    }
    
    this.lastSwitchTime = now;
    this.switchCount++;
    
    // 上报切屏事件
    this.reportSwitch(type);
    
    // 检查是否达到阈值
    if (this.switchCount >= this.maxSwitchCount) {
      this.handleMaxSwitchReached();
    }
  }
  
  // 上报切屏事件到服务器
  async reportSwitch(type) {
    try {
      const response = await fetch('/rtr/html/template/saveEventLog', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json;charset=UTF-8'
        },
        body: JSON.stringify({
          key: `screen-switch-${type}`,
          eventTime: new Date().toISOString(),
          info: JSON.stringify({
            type: type,
            count: this.switchCount,
            timestamp: Date.now()
          })
        })
      });
      
      const result = await response.json();
      
      if (result.code === 1001) {
        console.log('切屏事件上报成功', result);
      }
    } catch (error) {
      console.error('切屏事件上报失败', error);
    }
  }
  
  // 达到最大切屏次数
  handleMaxSwitchReached() {
    alert('您的切屏次数已达到上限，系统将强制交卷！');
    // 强制提交试卷
    this.forceSubmitExam();
  }
  
  // 强制提交试卷
  forceSubmitExam() {
    // 调用提交接口
    // ...
  }
}

// 使用示例
const monitor = new ScreenMonitor();

// 考试开始时启动监控
function startExam() {
  monitor.start();
  console.log('切屏监控已启动');
}

// 考试结束时停止监控
function endExam() {
  monitor.stop();
  console.log('切屏监控已停止');
}
```

### 5.2 服务端切屏计数
```javascript
// 伪代码：服务端处理切屏事件
app.post('/rtr/html/template/saveEventLog', async (req, res) => {
  const { key, eventTime, info } = req.body;
  const userId = req.session.userId;
  const examId = req.session.currentExamId;
  
  // 解析事件信息
  if (key.startsWith('screen-switch-')) {
    const switchData = JSON.parse(info);
    
    // 增加切屏次数
    await db.query(
      'UPDATE exam_records SET switch_count = switch_count + 1 WHERE user_id = ? AND exam_id = ?',
      [userId, examId]
    );
    
    // 获取当前切屏次数
    const record = await db.query(
      'SELECT switch_count, max_switch_count FROM exam_records WHERE user_id = ? AND exam_id = ?',
      [userId, examId]
    );
    
    // 检查是否超过限制
    if (record.switch_count >= record.max_switch_count) {
      // 标记为作弊
      await db.query(
        'UPDATE exam_records SET status = "cheating", end_time = NOW() WHERE user_id = ? AND exam_id = ?',
        [userId, examId]
      );
      
      // 通知前端强制交卷
      return res.json({
        code: 1002,
        msg: '切屏次数超限，强制交卷',
        data: { forceSubmit: true }
      });
    }
    
    // 记录日志
    await db.query(
      'INSERT INTO event_logs (user_id, exam_id, event_type, event_time, info) VALUES (?, ?, ?, ?, ?)',
      [userId, examId, 'screen_switch', eventTime, info]
    );
  }
  
  res.json({
    code: 1001,
    msg: '操作处理成功'
  });
});
```

## 六、防御绕过措施

### 6.1 前端绕过的常见手段
1. **删除事件监听器**：
   ```javascript
   document.removeEventListener('visibilitychange', ...);
   ```

2. **篡改 document.hidden**：
   ```javascript
   Object.defineProperty(document, 'hidden', { get: () => false });
   ```

3. **拦截 fetch/XMLHttpRequest**：
   阻止上报请求发送

### 6.2 防御措施
1. **服务端超时检测**：
   - 长时间无心跳或操作视为异常
   - 定期检查页面活跃状态

2. **代码混淆**：
   - 对监控代码进行混淆，增加逆向难度

3. **完整性校验**：
   - 定期检查监听器是否被移除
   - 检测 API 是否被篡改

4. **多重验证**：
   - 结合人脸识别、鼠标轨迹等多维度监控
   - 服务端日志分析异常行为

## 七、总结

### 7.1 核心技术栈
- **Page Visibility API**：检测标签页可见性
- **Window Blur/Focus**：检测窗口焦点状态
- **HTTP POST 上报**：实时上报切屏事件
- **服务端状态管理**：防篡改的计数器

### 7.2 优点
- 实现简单，兼容性好
- 无需额外插件
- 服务端控制，前端难以绕过

### 7.3 局限性
- 可能存在误报（如输入法弹窗、系统通知）
- 熟练的开发者可以通过浏览器调试工具绕过前端检测
- 需要结合其他防作弊手段（人脸识别、答题行为分析等）

### 7.4 改进建议
1. **增加误报容忍度**：区分短暂切屏和长时间离开
2. **智能判断**：分析切屏模式，识别正常行为（如查词典）
3. **用户提示**：在切屏时给予明确警告，而非直接计数
4. **开发模式开关**：开发调试时可以禁用检测
